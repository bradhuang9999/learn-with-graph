## 選圖原則

- SVG 只用於能幫讀者看懂**結構、流程、對比、判斷或失敗模式**的概念；不規定每節一張，也不以 SVG 取代 Markdown。下表的「可沿用」意指**素材候選**，不是已通過 v2 內容或視覺 QA。
- `舊圖 4.1` 指 [原 SVG 目錄](../key-points-svg/)中 `第04章/4.1 *.svg` 的唯一檔案；下方「126 張舊圖去向」逐一列出每個舊編號。`主`＝適合作本考點的主要來源，`輔`＝只取其中一部分或作交叉參照，`延伸`＝不進入考綱主線，`校正`＝先改錯再考慮沿用。
- 真正製作 v2 時先核對新筆記與官方考綱，再逐圖決定重用、拆分、合併或重畫；若改動視覺內容，使用專案的 `teaching-svg` 流程進行瀏覽器算圖與修復 QA。避免把 126 張原圖機械搬移或強制塞滿 30 節。
