# 參考與處理紀錄

此目錄保留 Claude CCAR-F 教材的整理說明、圖解 QA 報告，以及原始檔名到正式教材檔名的對照。網站與後續編修皆以 [`content/zh-TW/claude/ccar-f`](../content/zh-TW/claude/ccar-f) 為唯一教材來源。

- [`source-manifest.json`](claude/CCAR-F/source-manifest.json) 記錄 30 份 Markdown、34 張 SVG 的原始路徑、正式路徑與 SHA-256。移除重複檔案前，64 對檔案均逐位元相同。清單中的原始路徑是歷史記錄，檔案已不在此目錄。
- `key-points/` 的章節 README 與 `key-points-svg/README.md` 保留原教材編排和圖解處理脈絡；其中部分舊版相對連結指向已移除的副本，請以對照清單尋找正式教材。
- `key-points-svg/qa/` 保留 34 組圖解的 JSON 與截圖，作為當時的瀏覽器幾何檢查紀錄。這些紀錄不代表教學內容品質已通過審核。
